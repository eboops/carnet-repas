# NutriNote

Un carnet de suivi alimentaire **simple, sans compte ni publicité** : on note ce qu'on mange, le carnet calcule les calories et les protéines, puis on peut exporter son carnet pour le faire analyser par une IA de son choix.

Prototype HTML d'une future application Android.

- Prototype en ligne : https://eboops.github.io/carnet-repas/
- Dépôt : https://github.com/eboops/carnet-repas

Les données restent dans le navigateur de l'appareil. Effacer les données du navigateur efface aussi le carnet : faites régulièrement une sauvegarde dans un fichier (page Sauvegarde).
